# the Game of LIFE

인생게임 팀 프로젝트

## 🤝 협업 규칙
- `main` 브랜치에 직접 push하지 않고, 기능 브랜치를 만들어 PR로 합칩니다.
- 브랜치 이름: `타입/작업내용` (예: `feat/dice-roll`, `fix/board-render`)
- PR은 `.github/PULL_REQUEST_TEMPLATE.md` 양식에 맞춰 작성하고, 팀원 1명 이상 리뷰 후 머지합니다.

## 🎲 게임 소개 (프로토타입)

Nintendo 인생게임을 바탕으로 만든 2D 보드게임
아기로 태어나 → 유아 → 유치원 → 초·중·고 → 진로 선택 → 성인 초반 → 성인 후반 → 황혼기 → 골인!

## ▶ 실행 방법

### 1) 그냥 해 보기 (게스트)
`index.html` 더블클릭 → **게스트로 플레이**
(로그인·랭킹은 안 됨)

### 2) 로그인 · 랭킹까지 (서버 + MySQL)
1. **MySQL 설치** (MySQL Installer 또는 XAMPP)
2. `backend/schema.sql` 을 MySQL Workbench 에서 실행 → DB, 테이블 생성
3. `backend/.env.example` 을 복사해서 **`backend/.env`** 로 이름 바꾸고 MySQL 비밀번호 입력
4. **`서버실행.bat`** 더블클릭 → 브라우저에서 `http://localhost:8000`

## 📁 파일 구조 (팀원 역할 나누기 추천)

| 파일 | 내용 | 담당 추천 |
|---|---|---|
| `index.html` | 화면 뼈대 (로그인, 타이틀, 설정, 게임, 결과) | 프론트 |
| `style.css` | 디자인, 애니메이션 | 프론트 / 디자인 |
| `script.js` | 게임 규칙 (1~20번 구역) | 프론트 (게임 로직) |
| `events.js` | **스토리, 직업, 연애 상대, 이벤트 내용** | 기획 / 스토리 |
| `map.js` | 지도 칸 위치와 연결 (자동 생성) | 기획 (맵) |
| `api.js` | 서버 통신 (로그인, 기록, 랭킹) | 백엔드 연결 |
| `backend/main.py` | FastAPI 서버 | 백엔드 |
| `backend/schema.sql` | MySQL 테이블 | 백엔드 / DB |
| `assets/` | 그림 (임시) → `에셋_가이드.md` 참고 | 디자인 |
| `tools/make-map.js` | 지도 + 임시 그림 생성기 | 맵 |

> ⚠️ `tools/make-map.js` 를 다시 실행하면 `map.js` 와 임시 그림을 **덮어써요.**
> 지도를 손으로 고쳤다면 실행하지 마세요.

## 🎮 게임 규칙 (닌텐도 스위치 인생게임 사양서 기준)
- **게임 모드** : 🌈 평생 모드 **49턴** / 🧒 아이만 모드 **12턴** (고등학교 졸업 = 진로 선택 갈림길에서 정산) / 👔 성인부터 모드 **37턴** (능력치 50, 기초 자금 50만원으로 진로 선택부터)
  - 정해진 턴을 다 쓰면 골인 못 한 사람이 있어도 게임 끝 → 🏆 시상식 → 📜 인생 보고서
- 시작 전에 **👤 사람 수(1~4)**, 남은 자리만큼 **🤖 컴퓨터**를 +/- 로, 자리마다 **♂/♀ 성별** 선택
  - 컴퓨터는 룰렛 칸 수까지 계산해서 이득인 선택을 하고, 카드는 좋은 칸에 멈출 수 있을 때만 써요
  - 컴퓨터 차례의 선택지는 보이지만 사람이 대신 누를 수 없어요 (확인 버튼만 가능)
- 지도 : 312칸 (어린 시절 ≈ 12턴 분량, 어른 ≈ 37턴 분량)
- **이동 룰렛(1~10)** 만 숫자, 나머지 확률은 전부 **🎡 확률 룰렛** (10칸을 X 실패 / O 성공 / ◎ 대성공 으로 나눔)
- **3대 능력치** : 🧠 지력 · 💪 체력 · ✨ 센스 (0~100, 등급 F·E·D·C·B·A·S)
- **재능 룰렛**(유아 시절) : 재능 능력치는 항상 **1.5배**로 올라요
- **직업** : 성년이 되면 고르는데, 능력치가 모자란 직업은 잠겨 있어요 (랭크 ★1~★5)
  - **💵 월급날**은 지나가기만 해도 월급 (내 월급 + 배우자 + 어른이 된 자녀 - 대출 이자)
  - 월급날마다 **진급 심사 룰렛** : 룰렛 숫자 + 주 능력치×0.1 ≥ 15 면 RANK UP (능력치 조건이 모자라면 거부)
- **🏦 자동 대출** : 어른의 돈이 마이너스가 되면 1건(100만원)씩 자동 대출 → 월급날마다 1건당 이자 10만원 → 마지막에 1건당 150만원 상환
- **🤝 인연** : 다른 플레이어와 같은 칸에서 만나면, 수락 시 두 사람 모두 지력·센스 +15 (어린 시절·어른 한 번씩)
- **💘 연애** : 직업 랭크와 재산에 따라 **이성 상대 카드 3장** 중 선택 → 데이트 룰렛으로 호감도 UP
  - **💍 결혼 정지 칸** (또는 연애 칸 고백) : 호감도 = 프러포즈 성공 확률
  - 결혼 후 : 데이트(호감도 70%) / 특별한 데이트(20만원, 100%) → **👶 아기 룰렛** → **👦👧 성별 룰렛**
  - 아이는 월급날 4번이 지나면 어른 → **직업 룰렛** → 월급날마다 돈을 보태 줘요
  - 결혼 / 출산 때 **🎁 축의금 룰렛** (다른 사람 한 명마다 받기)
  - 말 아래에 배우자 · 자녀 **핀**이 붙어요
  - 🏝️ 황혼기에는 배우자 + 어른 자녀 수입이 **매 턴** 들어와요
- **🎴 카드** (최대 3장) : 🐢 작은 숫자(1~3) · 🚀 큰 숫자(7~10) · 5️⃣ 5 카드 · 🎯 저격(앞 5칸 안의 ⭐ 럭키 칸으로) · 🛡️ 수호(갖고만 있으면 갈취·함정을 1번 막고 반사)
- **⭐ 럭키 칸** : 럭키 룰렛 (어른은 돈, 어린이는 능력치) · **💎 보물 칸** : 보물 룰렛 (마지막에 자산에 더해짐)
- **📌 상황 이벤트** : 결혼, 자녀, 집, 대출, 재능, 예전에 한 선택(피아노, 연습생, 창업 ...)에 맞는 이벤트
- 갈림길 : 학원/운동장, 대학/취업, **💕 애정·가정 집중 / 💼 출세 집중**, 바닷길/**🎰 한방역전섬**
  - 한방역전섬에 들어가면 **카드 전부 압수**, ? 칸은 **인생 복권** (현금 절반을 걸고 7번 칸 ×2, 10번 칸 ×5)
- 한 턴(모두 한 번씩)마다 **🎮 미니게임** (🎁 상금 룰렛으로 1등 상금 결정, 미성년자는 능력치)
- 누군가 새 나이대에 들어가면 그 턴 끝에 **📋 중간 집계** (순위 변화, 순위 그래프, 상태)
- 먼저 골인하면 끝날 때까지 **🎰 보너스 룰렛**
- **🏆 시상식** : 보물 수집가 · 미니게임 킹 · 인연 부자 · 대가족 · 월급왕 (각 90만원)
- **최종 자산 = 현금 + 집 + 보물 - 대출×150만원** (골인 순서 보너스 · 칭호 상금은 현금에 포함)
- 돈은 1억이 넘으면 "1억 2500만원" 처럼 표시
